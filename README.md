# DineOut
=======
# React + Vite

## 🚀 Features

- **Create Orders**
  - Enter customer name
  - Select items (Hamburger, Chicken Nuggets, Submarine Sandwich, Juice,
Ice Cream, Tea)
  - Place the order with total price calculation

- **Order Summary**
  - View total orders
  - See pending and delivered counts

- **Order Reports**
  - Displays:
    - Order ID
    - Customer name
    - Item count
    - Total price
    - Order status (Delivered/Pending)
  - Update order status or delete orders

- **Filter Functionality**
  - Filter orders by status (All, Pending, Delivered)

---

## 🖼️ UI Overview

- **Left Panel (Create Order)**
  - Customer name input
  - List of food items with price and add button
  - Order total and "Place Order" button

- **Right Panel (Dashboard)**
  - Summary boxes for Total, Pending, and Delivered orders
  - Scrollable table showing all orders with control buttons
